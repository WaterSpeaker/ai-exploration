## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Timeline sessions

Each session uses one of two surfaces on `TimelineSection`:

- `surface="panel"` — Limestone bottom background card (01 About). Optional `tone="dark"` for Obsidian panel (02 AI in E-Commerce). Contact 05 is a custom dark panel.
- `surface="flush"` — no bottom background card, content on Pumice canvas (03 D2C workflow, 04 Vibe Coding)

See `.cursor/rules/timeline-session-surfaces.mdc`.
