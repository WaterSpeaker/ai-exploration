多种Try-on方式 // Various Try-on Methods

用户不下单，经常是因为看不到实物效果、拿不准。我们可按品类做专属体验：美妆墨镜，用AR实时上脸对比；鞋包服饰。提供360度细节展示；家居用品，支持等比虚拟摆放。用直观体验帮用户打消顾虑，快速决策。

信息总结提炼 // Information summary and extraction

基于商品评论、短视频的卖点信息等进行总结提炼，帮助用户快速获取核心信息

多模态内容推荐 // Multimodal content recommendation

在为用户推荐商品时，同步展示商品评论总结和关联短视频，提供更丰富的信息帮助用户做出购物决策；

下单后，为用户推荐商品使用说明相关视频，帮助用户更好地使用。

购买top brands 商品时，同步为用户推荐官方品牌店铺，作为更明确的商品资质认证。

更清晰的售后服务引导 // Better after-sale service

预期收益：Aftersales CPO↓, CSAT↑

基于现有Platform IM的售后与AI能力，在售后详情页提供更清晰且可触达的售后状态引导。着重呈现如下几个容易引起不满和困惑的状态，减少当前复杂信息 & 不清晰退货流程对用户的影响：

  • Refund timeline (退款什么时候到账，什么原因导致到账迟滞，是否存在预付款影响等)
  • Return process (退货进度如何，商家是否有收到退换商品)
  • Abnormal scenarios (Payment failures, rejected reasons)

导购助手基础体验优化 // AI assistant optimization

预期收益：导购助手内用户停留时长↑，对话轮次↑，交易转化↑，用户留存↑

开屏意图明确 & 不同场景下的开屏体验差异化 // Welcome experience

当前，用户对导购助手的定位不太明确，问了很多导购助手能力外的问题，如售后相关、达人合作咨询等。此外，开屏即走的用户比例也比较高。

因此，希望通过优化开屏页，为用户提供更多具体场景，让用户在进入时就对导购助手的能力有大致预期，并能更容易地开始对话。

此外，FY26 我们也会探索导购助手在更多场景嵌入的可能性，也需要基于不同场景的不同用户咨询意图，做更为个性化的开屏内容呈现。

基于商品的深度操作 // Product-based advanced operations

当用户对某个商品特别感兴趣时，可通过快捷手势（如长按、左滑等）进一步操作，如收藏、加购、商品详情追问、与其余商品进行对比等。

浏览商品过程中快捷进入咨询 // Shortcut for AI assistant

浏览商品返回时，可通过拖拽商品进入导购助手，快速开始咨询该商品
