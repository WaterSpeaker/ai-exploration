• 定义国际电商 C 端整体 AI Design Language：在继承 TikTok 主端规范的基础上，补齐电商场景所需的颜色体系、分层图形识别与文案规范，让用户能清晰识别 AI 功能；
  • 后续在整体设计团队内进行宣讲，并复用于多个 AI 产品子域，以保证端内 AI 设计语言一致性。

项目背景

随着 AI 技术的持续发展，国际电商 C 端也在探索 AI 应用能为业务提供哪些增量价值。目前的探索包括AI导购助手、虚拟试衣试妆、智能评论总结、智能尺码推荐等。

在探索初期，由于缺少统一设计指导原则，导致：1) 不同 AI 功能的设计语言不一致，未给用户传递统一心智；2) 在设计方案评审，尤其涉及跨团队沟通时，难以衡量什么样的设计范式才是适当的。

因此，我们希望定义一套 AI 设计原则，为后续项目提供指导。

视觉规范

TikTok 主端提供了 AI 相关的视觉识别指导 AI相关功能品牌规范 | AI-related functions Brand Guidelines，其更专注于生成式创作领域。而在电商场景，我们希望在整体保障 TikTok 用户体验一致性的前提下，做出如下拓展：

颜色识别

TikTok主端定义的AI主色为亮绿色，但为了避免其过于冷静而不适用电商氛围，提供辅助紫色用于渐变色构建。

主色

EC/Theme/Ai/Main 色组 - 用于 icon 等识别元素着色

渐变色

EC/Theme/Ai/Gradient 色组 - 用于 border 等装饰元素渐变着色。

不推荐使用过于多彩的渐变，避免脱离品牌基调。这里的多彩指超过 3 个色相的颜色渐变或冷暖相差过大的颜色渐变。

渐变背景色

EC/Theme/Ai/Ambient 色组 - 用于卡片背景等辅助元素渐变着色

Dos and dont's

Guidance

Do

Don't

使用文字，或四角星图案作为 AI 通识符号，用于功能强调、吸引。机器人形象仅代表该功能与对话相关，并不是通用的 AI 形象 IP。

具体场景应用

功能标题 Feature title

  • 目标 ：帮助用户进行AI场景确认，快速识别当前模块用途
  • 做法 ：「标题」与「四角星元素」角标结合使用

行为操作 CTA

  • 目标：明确告知用户“AI可帮助执行的下一步”，让用户更快达成目标
  • 做法：图标库中含有「四角星元素」的图标与「操作文案」结合使用

生成加载 Generation loading

  • 目标：清晰展示“AI 正在为你生成内容”，提供进度反馈，增加可靠性
  • 做法：含有「四角星元素」的动画与「加载文案」结合使用

生成注释 Generation annotation

  • 目标：告知用户内容由AI生成，提高数据来源透明度，降低决策风险
  • 做法：仅使用文字，不使用图形，需要进一步解释说明时加 info icon

Label AI-generated content.

Include legal disclaimers with any tool that creates AI-generated content.

Users must be able to review AI-generated content before posting. Users should be notified they are responsible for AI-generated content and that it adheres to platform policies.

AI content generation tool shows disclaimer

AI features that don't generate content may not need to be labeled (e.g., search).

AI may not require labeling if used as an extension of technology like machine learning.

Brand name matching function uses AI on backend

Disclose AI function if a user may interpret it as human.

If there could be confusion whether AI content might have been created by a human, it should be disclosed as AI.
